# 01 · PRISMA 2020 总览

## 1.1 PRISMA 是什么

PRISMA = **Preferred Reporting Items for Systematic Reviews and Meta-Analyses**，系统综述与荟萃分析的报告规范。

- 前身是 2009 年的 PRISMA（更早可追溯到 1999 年的 QUOROM）。
- 2020 版于 2021 年 3 月发表，为反映方法学十余年的发展而全面改写。
- 同一篇声明同时发表在 *BMJ*、*PLOS Medicine*、*Journal of Clinical Epidemiology*、*Systematic Reviews*、*International Journal of Surgery* 五本期刊上，以最大化可及性。
- 清单与流程图以 **CC BY 4.0** 发布，可自由改编、翻译、再分发，只需署名。

## 1.2 PRISMA 2020 套件由什么组成

| 组成部分 | 内容 | 用途 |
|---|---|---|
| **主声明论文**（BMJ 2021;372:n71） | 27 条清单 + 扩展版清单 + 摘要清单 + 流程图模板 | 投稿时随文提交 |
| **开发论文** | 更新过程、每条修改的理由 | 想知道"为什么这样改"时读 |
| **解释与详述论文**（E&E, BMJ 2021;372:n160） | 每条的理由 + 报告要点 + **优秀范例** | 真正写作时逐条对照读 |
| **流程图模板** | 4 个 Word 模板（新综述/更新综述 × 是否含其他检索途径） | 画 PRISMA flow |
| **Shiny App / R 包** | 在线填清单、自动生成流程图 | 省事工具 |

> 实操建议：**不要只看 27 条清单**。清单每条只有一两句话，真正的操作细则在 E&E 论文里（每条有 bullet 级的报告要点和范例）。清单是检查表，E&E 是说明书。

## 1.3 PRISMA 不是什么（三条边界）

### ① 不是实施规范（conduct guideline）
PRISMA 只回答"写出来的报告里必须有什么"，不回答"该怎么做这项综述"。

- 实施方法 → **Cochrane Handbook for Systematic Reviews of Interventions**（干预类）、**JBI Manual for Evidence Synthesis**（含质性/混合方法）。
- 但两者高度耦合：如果某条 PRISMA 条目你"没法报告"，通常说明你在实施阶段就漏做了。所以实践中把 PRISMA 当作**实施阶段的产出物清单**来用，是最高效的做法。

### ② 不是质量评价工具
不能用"这篇综述符合 PRISMA 24/27 条"来判断它可信。报告完整 ≠ 方法可靠。

- 评价一篇已发表综述的质量 → **AMSTAR 2**（16 条，其中 7 条为关键条目）
- 评价一篇综述的偏倚风险 → **ROBIS**（3 阶段、4 个领域）
- 同理：**绝不能把报告规范当成纳入研究的质量评价工具**（例如用 CONSORT 打分来评价 RCT 质量），这是文献中常见的方法学错误。

### ③ 不是所有综述类型的通用清单
PRISMA 2020 主要针对"评价干预效果"的系统综述设计，但其结构也适用于其他类型的系统综述。若综述类型特殊，应改用对应扩展（见 `10-extensions.md`）：

- 范围综述 → **PRISMA-ScR**
- 网状荟萃分析 → **PRISMA-NMA**
- 诊断准确性 → **PRISMA-DTA**
- 个体参与者数据 → **PRISMA-IPD**
- 方法学/技术类综述（如本项目）→ 无专用扩展，需**显式声明改编方式**（见 `13-applying-to-this-project.md`）

## 1.4 27 条的结构

```
TITLE            1            标题即声明是系统综述
ABSTRACT         2            见摘要清单（12 条）
INTRODUCTION     3–4          理由、目标
METHODS          5–15         纳排 / 信息源 / 检索式 / 筛选 / 提取 / 数据条目 /
                              偏倚风险 / 效应量 / 综合方法(13a–f) / 报告偏倚 / 证据确信度
RESULTS          16–22        筛选结果(16a–b) / 研究特征 / 偏倚 / 单研究结果 /
                              综合结果(20a–d) / 报告偏倚 / 确信度
DISCUSSION       23a–d        解释 / 证据局限 / 过程局限 / 意义
OTHER INFO       24–27        注册与 protocol(24a–c) / 资助 / 利益冲突 / 数据与代码可得性
```

含子条目共 42 个检查点。**方法学的重心在 5–15 与 20a–d**：这两组条目决定了这篇综述是否可重复。

## 1.5 2009 → 2020 的 11 项主要变化（Box 2）

这些变化基本都指向同一个方向：**从"报告做了什么"升级为"报告到足以被复现和被质疑"**。

| # | 变化 | 为什么重要 |
|---|---|---|
| 1 | 摘要清单并入主声明 | 多数读者只读摘要，摘要必须自足 |
| 2 | 注册与 protocol 独立成节（24a–c），新增"修订说明"子条 | 可追踪事后变更，防选择性报告 |
| 3 | 检索式要求给出**所有**数据库的完整策略（2009 只要求至少一个） | 检索可复现是系统综述的底线 |
| 4 | 筛选条目要求写明**几人、是否独立、是否用自动化工具** | 单人筛选与 AI 辅助筛选的风险必须透明 |
| 5 | 数据条目拆成 10a（结局）与 10b（其他变量），并要求说明"同一结局多个结果时怎么选" | 防止挑选最漂亮的那个结果 |
| 6 | 综合方法由 1 条扩成 6 个子条（13a–f） | 综合过程是最容易含糊其辞的环节 |
| 7 | 新增 16b：**引用那些看似符合纳入标准却被排除的研究并说明理由** | 让读者能挑战你的排除决定 |
| 8 | 综合结果拆成 4 个子条（20a–d） | 异质性与敏感性分析必须单独报告 |
| 9 | 新增证据确信度评价（方法 15 / 结果 22） | GRADE 进入标准报告要求 |
| 10 | 新增利益冲突声明（26） | — |
| 11 | 新增数据、代码与材料可得性（27） | 开放科学要求；对计算类综述尤其关键 |

## 1.6 怎么把 PRISMA 真正用起来

1. **写 protocol 时**：以 PRISMA-P 17 条为骨架（`06`），但同时把 PRISMA 2020 的 5–15 条抄成小标题，逐条填写。protocol 写不出来的条目，就是你还没想清楚的方法。
2. **执行时**：把 16a 的流程图计数表建成一个实时更新的表格（`05`），不要等写作时回忆。
3. **写作时**：用官方清单的第三列 "Location where item is reported" 填页码/章节号，投稿时作为补充材料上传。
4. **自查时**：对照 `12-pitfalls.md`，再用 AMSTAR 2 自评一遍。
5. **发表后**：若做 living review，按 PRISMA-Living SR 的要求报告更新频率与检索重跑记录。
