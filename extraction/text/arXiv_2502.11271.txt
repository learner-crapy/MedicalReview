B.3      Additional Tools for Exploration Study
We also provide several additional tools for explo-
ration, as follows:
   Object Detector (§F.1) performs object detection
on an image given a list of object labels to detect, using
the Grounding DINO model (Caron et al., 2021). Due
to the standardized design of tool cards, this tool can
be upgraded to the Advanced Object Detector (§F.2),
which uses DINO-X (Ren et al., 2024), a more recent
version powered by API calls.6

news articles from the science journal Nature.7 An
example in §G.8 demonstrates how this tool can be
used to obtain the latest research trends for a given
topic.
