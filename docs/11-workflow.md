# 11 · 端到端流程：15 步

PRISMA 管报告，这一份管**做**。每一步给出：做什么、产出物、对应的 PRISMA 条目、进入下一步的门禁条件。

```
① 预检索  ② 定类型  ③ 定问题  ④ 定纳排  ⑤ 写protocol  ⑥ 注册
   ↓
⑦ 建检索式  ⑧ 同行评议  ⑨ 正式检索  ⑩ 去重  ⑪ 双人筛选
   ↓
⑫ 提取  ⑬ 偏倚评价  ⑭ 综合+确信度  ⑮ 撰写+开放材料
```

---

### ① 预检索（scoping search）
**做什么**：粗检一遍，判断该领域有多少研究、是否已有同题综述（查 PROSPERO、Cochrane Library、Epistemonikos）。
**产出**：已有综述清单 + 粗略命中量估计 + 10 篇左右的 sentinel papers。
**条目**：3（理由）。
**门禁**：若已有近期高质量同题综述，必须能说清你的差异（范围/时间/方法/新证据）；说不清就换题。

### ② 确定综述类型
**做什么**：系统综述？范围综述？证据地图？混合（先地图后综合）？
**产出**：类型决定 + 对应的报告规范（见 `10`）。
**门禁**：类型与问题匹配——能提出可比较问题才做系统综述。

### ③ 形成问题
**做什么**：用 PICO 或改编框架写出有明确自变量与因变量的问题；区分主问题与子问题。
**产出**：问题陈述 + 框架表 + 概念模型（哪些因素影响结局）。
**条目**：4。
**门禁**："What is known about…" 一律打回。

### ④ 确定纳排标准
**做什么**：逐要素写标准；剔除所有"纳入标准的镜像否定"；为每个限制写科学理由；确定综合分组规则。
**产出**：纳排标准表 + 分组规则。
**条目**：5。
**门禁**：另一个人拿着标准能独立复现你对 10 篇 sentinel paper 的判断。

### ⑤ 撰写 protocol
**做什么**：按 PRISMA-P 17 条逐条写（见 `06`），特别是：主要结局、亚组清单、偏倚评价工具、综合方法、无法定量合并时的替代方案。
**产出**：protocol 文档 + 修订记录机制。
**门禁**：17 条全部有内容；亚组与敏感性分析清单已冻结。

### ⑥ 注册
**做什么**：PROSPERO（健康结局）或 OSF（其他）。
**产出**：注册号 / DOI。
**条目**：24a、24b。
**门禁**：注册完成之前不开始正式检索。

### ⑦ 建检索式
**做什么**：分面分析 → 收集自由词与受控词 → 逐库转换（见 `07`）。
**产出**：分面表 + 每个库的完整检索式。
**条目**：6、7。
**门禁**：sentinel paper 召回率 100%。

### ⑧ 检索式同行评议
**做什么**：按 PRESS 清单请信息专家或同行复核布尔逻辑、受控词、限制条件。
**产出**：评议记录 + 修改后的检索式。
**条目**：PRISMA-S 条目 14。

### ⑨ 正式检索
**做什么**：逐库运行并导出；同时做引文追溯（前向/后向）、灰色文献、注册库、必要时联系作者。
**产出**：各库原始导出文件 + 记录数 + 精确检索日期。
**条目**：6、PRISMA-S 15。
**门禁**：每个来源的记录数与日期都已登记。

### ⑩ 去重
**做什么**：软件自动去重 + 人工抽查；把同一研究的多份报告标记为一组（预印本/会议/期刊）。
**产出**：去重后库 + 去重方法说明。
**条目**：PRISMA-S 16；流程图。

### ⑪ 筛选（1-2-3 三阶段）
**做什么**：① 标题 → ② 摘要 → ③ 全文（全文阶段主要看**方法部分**：对象、干预/暴露、结局测量）。双人独立，用 yes/no/maybe 三分类，不确定一律留到下一阶段；先做一批校准再铺开。
**产出**：筛选记录表 + 全文排除表（每篇一个主要理由）+ 流程图计数。
**条目**：8、16a、16b。
**门禁**：全文排除理由已分类编码；流程图加减法自洽。

### ⑫ 数据提取
**做什么**：先在 3–5 篇上预试提取表，锁定版本后双人独立提取；对缺失信息按预设规则处理，必要时联系作者。
**产出**：提取表（建议以 study × 比较条件为行）+ 假设规则说明。
**条目**：9、10a、10b。
**门禁**：提取表字段与 protocol 的数据条目一致；同一研究多报告的归并规则已应用。

### ⑬ 偏倚风险评价
**做什么**：用设计匹配的工具或预注册的自建领域（见 `09`）；双人独立 + 校准；逐领域判断 + 理由。
**产出**：逐研究 × 逐领域的判断表。
**条目**：11、18。
**门禁**：没有合成总分；每个判断都能追溯到原文位置。

### ⑭ 综合与确信度
**做什么**：先判断能否荟萃分析；能则合并 + 异质性 + 亚组 + 敏感性；不能则走 SWiM 九条。之后对每个主要结局做 GRADE。
**产出**：森林图或综合表 + 异质性与敏感性结果 + SoF 表。
**条目**：12、13a–f、14、15、19、20a–d、21、22。
**门禁**：方法里承诺的每一项分析都有对应结果；偏倚评价真的进入了综合。

### ⑮ 撰写与开放材料
**做什么**：按 27 条结构写正文，用官方清单填"item 报告在哪一页"；讨论按"主要发现 → 强弱 → 意义 → 启示"四段式；上传数据、提取表、代码。
**产出**：正文 + 已填写的 PRISMA 清单 + 流程图 + 补充材料 + 仓库 DOI。
**条目**：23a–d、24c、25、26、27。
**门禁**：protocol 的每处偏离都在 24c 说明；结论不超出证据。

## 时间与人力的现实估计

| 阶段 | 典型耗时（2 人团队） |
|---|---|
| ①–⑥ 选题到注册 | 3–6 周 |
| ⑦–⑨ 检索 | 1–2 周 |
| ⑩–⑪ 去重与筛选 | 2–8 周（取决于命中量；每千条题录约 8–12 人时） |
| ⑫–⑬ 提取与评价 | 4–10 周（每篇 1–3 人时） |
| ⑭ 综合 | 2–4 周 |
| ⑮ 撰写 | 4–8 周 |

单人完成也可行，但必须：对一定比例样本做自我交叉复核（间隔时间后重筛）、在 23c 如实声明、尽量为筛选与提取引入第二人做抽样验证。

## 迭代回路（允许且必须记录的三种）

1. **sentinel paper 未被检出** → 回到 ⑦ 改检索式，并记录这次迭代。
2. **筛选者频繁分歧** → 回到 ④ 澄清纳排标准，记录澄清内容与时点。
3. **数据不足以支持预定综合** → 回到 ⑭ 按 protocol 修订流程改用替代方案，在 24c 说明，并做敏感性分析——**不是事后挑一个好看的方案**。
