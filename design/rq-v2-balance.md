## 1. 主旨与主问题

**主旨**：现有多代理框架以性能为唯一目标，普遍不报告、也不优化推理成本。本综述不问"谁更强"，而问**在什么条件下、多花多少成本、换来多少增益才算划算**。

**主问题**
> 在文本型医学考试问答上，LLM 多代理系统相对匹配单代理基线的**准确率增益（ΔAcc）与其成本代价（R）如何权衡**？在**模型参数规模 × 代理数量 × 协作机制 × 题目难度**的哪些组合下，能以可接受的成本获得有意义的增益（balance point）？

**核心量由单值改为二元组 + 三个派生量**

| 量 | 定义 | 说明 |
|---|---|---|
| `ΔAcc` | `Acc_MAS − Acc_baseline`（pp） | 仍只在同一研究内配对计算，绝不跨论文平均绝对准确率 |
| `R` | `Cost_MAS / Cost_baseline`（倍） | **主口径 = 每题 LLM 调用次数**（可由架构推算：`n_agents × n_rounds (+ 聚合调用)`），次口径 = 每题总 token，三口径 = 美元（同论文同计价日） |
| `RRB` | `ΔAcc / (100 − Acc_baseline)` | 错误率缩减比，消除天花板效应 |
| `CEI` | `ΔAcc / log₂(R)` | 单位成本增益。用 log₂ 是因为成本按倍数增长（2× 换 +2pp 与 32× 换 +4pp 不可同日而语） |
| `ICAR` | `(R − 1) / ΔAcc` | **增量成本—准确率比**：每多得 1 pp 需额外付出多少倍推理成本。ΔAcc ≤ 0 时记 `dominated` |

> `R` 的关键可得性判断：**即使论文不报告成本，只要描述了架构（代理数、轮数、是否有聚合器），`R` 就可推算**，标 `cost_source = derived`。这使 balance 分析的样本量远大于"报告了成本"的论文数。

## 2. 四个子研究问题

### RQ1 · 基线与可比性地基（描述层，必答）
> 现有研究在目标基准上使用了哪些**单代理基线、数据集切片、样本量与抽样方式**？据此可划分出哪些**可比评测组（evaluation group, EG）**，各组的基线准确率与基线成本基准是多少？**同一评测组内、同一 backbone 的基线准确率在不同论文间的离散度有多大？**

产出：
1. 评测组划分表（见 §4.1）
2. 每个 EG 的基线 Acc 分布（中位数、IQR、全距）
3. **跨论文可比性上界**：同 EG 同 backbone 的基线 Acc 极差 `δ_base`。**任何小于 `δ_base` 的跨论文 ΔAcc 差异都不构成证据**——这个数字本身就是本综述的一个硬结论，也是后续所有 Type C 对比的解释门槛。

### RQ2 · 代理数量 × 模型规模（balance 的第一维）
> 在同一评测组内、**模型参数规模带相同**的前提下，不同**代理数量档**的 ΔAcc、成本比 R 与单位成本增益 CEI 如何变化？是否存在**收益递减拐点**？

产出：每个数据集一张 `模型规模带 × 代理数量档` 矩阵（见 §4.2），外加 ΔAcc–R 曲线与拐点估计。

### RQ3 · 机制要素（balance 的第二维）
> 在**代理数量档与模型规模带固定**时，各机制要素（RAG / 辩论 / 角色分工 / 异质模型 / 验证者 / 聚合方式 / 自适应早停）各自带来多少 ΔAcc、多少成本增量？哪些是**低成本高收益**，哪些是**高成本低收益**？

关键约束：RAG 与工具带来的增益必须**归给 RAG/工具**，不得计入"多代理协作"的收益——这是本综述对现有文献最主要的方法学纠正。

### RQ4 · 题目难度（balance 的第三维）
> 在**代理数量、模型规模带、机制均固定**时，不同**题目难度**下的 ΔAcc 与 CEI 如何变化？"对难题多花钱、对简单题少花钱"这一直觉策略，是否有证据支持？难度自适应路由相比固定配置能否改善 balance？

## 3. 变量与分档标准

### 3.1 模型参数规模带（回答"多少以内算同等规模"）

按 `log₁₀(active parameters)` 度量（MoE 用 active，不用 total）。

| 用途 | 判据 | 说明 |
|---|---|---|
| **严格同带**（用于主对比） | `\|log₁₀N_A − log₁₀N_B\| ≤ 0.15`（≈ 1.4× 以内） | 7B vs 8B vs 9B 同带；7B vs 13B 不同带 |
| **宽松同带**（用于描述性表格） | `≤ 0.30`（≈ 2× 以内） | 7B vs 13B 勉强同带，须标注 |

分档（展示用）：

| 档 | 范围 | 典型 |
|---|---|---|
| S1 | ≤ 4B | 边缘/小模型 |
| S2 | > 4B – 10B | 7–8B 类 |
| S3 | > 10B – 35B | 13B / 32B 类 |
| S4 | > 35B – 90B | 70B 类 |
| S5 | > 90B（开源权重） | 100B+ |
| S6 | **闭源未披露** | 按厂商 × 版本 × 调用日期单独成层，**永不与 S1–S5 混合做规模推断** |

> 0.15 / 0.30 这两个切点是**本综述的预设约定**，理由：缩放律下性能是参数量的幂律函数，等对数间距才是自然尺度；主流开源家族的发布间距约为 2×，取其一半（1.4×）可保证"同带内不跨发布档"。**是否已有更权威的既有分档标准，待检索确认后在 protocol 中补引或替换。**

### 3.2 代理数量档

| 档 | 代理数 | 典型形态 |
|---|---|---|
| A1 | 2 | 生成器—批评者、二人辩论 |
| A2 | 3–4 | 三人投票、小型专科组 |
| A3 | 5–7 | 多专科会诊 |
| A4 | ≥ 8 | 大型代理群 |
| A5 | 动态/不定 | 按需招募、难度路由 |

**同时必须记录调用预算档**（成本的真实驱动量，比代理数更贴近 balance）：

| 档 | 每题 LLM 调用数 | |
|---|---|---|
| B1 | ≤ 3 | 轻量 |
| B2 | 4–9 | 中等 |
| B3 | 10–29 | 重 |
| B4 | ≥ 30 | 极重 |

> 代理数是**结构**，调用预算是**代价**。二者必须同时呈现——5 个代理 1 轮（5 次调用）与 2 个代理 5 轮（10 次调用）不是同一个成本量级。

### 3.3 机制要素（改为正交 flags，不再用互斥大类）

机制 flags 按四个功能块组织，便于 RQ3 按"哪一块最划算"汇报。`★` = 指定为 Type B 主对比因子（P0）。

**块 1 · 交互结构**（决定通信量，是 token 成本的主要结构性来源）

| flag | 取值 | 备注 |
|---|---|---|
| `m_debate` ★ | Y/N | 是否有多轮互评/反驳 |
| `m_topology` | full / star / chain / tree | **新增**。全连接的消息量随代理数呈 O(n²)，星型/链式为 O(n)。同样 5 个代理，拓扑不同成本可差数倍——这是除轮数外最大的结构性成本杠杆 |
| `m_hier` | Y/N | 是否有协调者/上级代理（与 topology=tree/star 高度相关，两者都记以便交叉核对） |
| `m_parallel` | parallel / sequential / mixed | **新增**。不改 token 成本，但决定**延迟**；临床部署中延迟是独立的成本维度 |

**块 2 · 信息流**（决定每次调用的上下文长度，是 token 成本的另一主源）

| flag | 取值 | 备注 |
|---|---|---|
| `m_context` | full_transcript / summary / answer_only | **新增**。代理看到的是完整转录、摘要还是只有他人答案。第 k 轮的上下文长度差异可达一个数量级，却几乎没有论文把它当变量研究——**预计产出为证据缺口结论** |
| `m_rag` ★ | Y/N | 是否检索增强（**基线是否同权限必须同时记录**） |
| `m_rag_source` | textbook / guideline / literature / KG / web / mixed | **新增**，`m_rag = Y` 时必填 |
| `m_tool` | Y/N | 是否调用工具 |
| `m_memory` | none / within_question / cross_question | **新增**（可选）。跨题记忆在考试式 QA 中罕见，若出现须单独标注（可能构成跨题信息泄漏） |

**块 3 · 角色与知识**

| flag | 取值 | 备注 |
|---|---|---|
| `m_role` ★ | Y/N | 是否有角色分工 |
| `m_role_type` | medical_specialty / functional / mixed / NA | **新增**。区分"心内科医生/放射科医生"这类**医学专科角色**与"分析者/批评者/总结者"这类**通用功能角色**。二者成本相同而机制假设完全不同——医学专科角色是否真的比通用角色更有用，是一个便宜且有意思的问题 |
| `m_hetero` ★ | Y/N | 是否使用不同模型 |
| `m_finetuned` | none / role_ft / domain_ft | **新增**。角色是靠提示还是靠微调实现。它把成本从推理端搬到训练端，直接关联"微调一个小模型 vs 编排一个大模型"这一 balance 命题 |

**块 4 · 答案生成与质控**

| flag | 取值 | 备注 |
|---|---|---|
| `m_agg` ★ | vote / judge / synthesis / rank | 最终答案如何产生。`vote` 几乎零成本，`judge`/`synthesis` 要额外调用——**便宜的聚合是否够用**是 RQ3 最直接的 balance 问题 |
| `m_confidence` | Y/N | **新增**。代理是否输出置信度并参与聚合。这是一个近乎零成本的机制，若能替代昂贵的多轮辩论，就是典型的高性价比发现 |
| `m_verify` ★ | Y/N | 是否有独立验证/批评环节 |
| `m_selfrefine` | Y/N | **新增**。单代理自我修正循环。必须与跨代理批评区分开，否则"多代理收益"里混进了"单代理多迭代"的收益（归因约束 C3） |
| `m_abstain` | Y/N | **新增**（可选）。系统能否弃答或转人工。临床上重要，考试式 QA 中预计极少见——若确实为零，本身就是值得写的缺口 |

**块 5 · 归因对照臂与控制策略**（不是协作机制，但必须编码）

| 字段 | 取值 | 备注 |
|---|---|---|
| `ctl_selfconsistency` | Y/N + `k` | **新增，重要**。单代理采样 k 次投票。它与 MAS 花同样的钱却不需要任何协作——**"同等调用预算下，MAS 能否打赢 self-consistency@k"是本综述最尖锐的一问**，见 C3.9 |
| `ctl_adaptive` | Y/N | 原 `m_adapt`。按你的意见**已移出机制块**：它不是协作机制而是成本控制策略。保留为控制策略字段，只服务 C4.3（难度自适应路由 vs 固定配置）。**若你要连 C4.3 一并去掉，此字段可整条删除** |

**组合爆炸的处理**：14 个 flags 无法两两全对比。指定 **6 个 ★ 主对比因子**（`m_debate` / `m_rag` / `m_role` / `m_hetero` / `m_agg` / `m_verify`）进入 Type B 主对比（P0）；其余作为描述性协变量与亚组，仅在恰好存在消融时报告。**`m_topology` 与 `m_context` 是最大的两个成本杠杆，但预计极少有论文做过消融——它们大概率以"证据缺口"的形式进入结论，这一结果本身对 balance 主旨是有力的。**

> 改用正交 flags 的两个理由：① 可以做"单要素有/无"的公平对比，正是你要的；② 互斥大类会把每个类别的 k 切得极碎，正交 flags 显著提高可用样本量。

## 5. 对照类型与公平性规则（方法核心）

你强调"撇开模型规模讨论框架是不公平的"——把它制度化为三级对照：

| 类型 | 定义 | 用途 | 证据强度 |
|---|---|---|---|
| **Type A** | 同一论文内 MAS vs 匹配单代理基线 | 计算 ΔAcc、R 的基本单元 | 高 |
| **Type B** | **同一论文内只变一个因子**的消融（代理数阶梯 / 机制有无 / 模型规模阶梯），其余全部固定 | **RQ2/RQ3/RQ4 的唯一合格调节效应证据** | 高（因子内配对） |
| **Type C** | 不同论文但落在同一格（同 EG + 同规模带 + 同代理档 + 同机制） | **仅描述性**，必须与 RQ1 的 `δ_base` 并列呈现 | 低 |

**三条硬规则**
1. 任何"A 机制比 B 机制好"的**因果性/调节性陈述**必须有 Type B 支撑；只有 Type C 时一律写作"描述性差异，幅度 x pp，低于/高于同组基线离散度 `δ_base`"。
2. 对比某一变量时，其余变量必须落在**同一格**（EG 相同、规模带严格同带、代理档相同、被对比之外的机制 flags 相同）。做不到就降级为 Type C。
3. **RAG/工具单独扣除**：`m_rag = Y` 且基线无检索权限的行，不进入"多代理协作收益"的任何主表，只进 RQ3 的 RAG 专项。

**方法学定位**：整体是 *evidence and gap map（EGM）+ 分层的研究内对照综合*；balance 侧用 **Pareto 支配分析 + 增量成本—效果比（ICAR，卫生经济学 ICER 的类比）**。ICER 类比对医学期刊审稿人是现成的语言，且天然适配"愿付阈值"表述：在"每 1 pp 愿付 k 倍成本"的阈值下，哪种配置最优——可画成本—效果可接受性曲线。
