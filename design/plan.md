**三条贯穿约束**（每一节都受其约束）

1. **对照显式**：结局是相对匹配单代理基线的差值，不是绝对准确率；绝不跨论文平均绝对准确率。
2. **成本成对**：任何准确率结论必须伴随成本结论，二者同表呈现。
3. **归因分离**：增益必须可归因于多代理协作本身，而非 RAG、工具、更多采样或更大推理预算。

## 1. 研究问题

### 1.1 主问题

> 在文本型医学考试问答上，LLM 多代理系统相对匹配单代理基线的**准确率增益与成本代价如何权衡**？在**模型规模 × 代理数量 × 协作机制 × 题目难度**的哪些组合下，能以可接受的成本获得有意义的增益？

### 1.2 结局：二元组 + 三个派生量

| 量 | 定义 | 说明 |
|---|---|---|
| `ΔAcc` | `Acc_MAS − Acc_baseline`（pp） | 同一研究内配对计算 |
| `R` | `Cost_MAS / Cost_baseline`（倍） | 主口径 = **每题 LLM 调用次数**；次口径 = 每题总 token；三口径 = 美元（同论文同计价日） |
| `RRB` | `ΔAcc / (100 − Acc_baseline)` | 错误率缩减比，消除天花板效应 |
| `CEI` | `ΔAcc / log₂(R)` | 单位成本增益 |
| `ICAR` | `(R − 1) / ΔAcc` | 每多 1 pp 需额外付出多少倍成本；`ΔAcc ≤ 0` 记 `dominated` |

**关键可得性**：`R` 可由架构描述推算（`n_agents × n_rounds` + 聚合调用），**不依赖论文是否报告成本**，推算行标 `cost_source = derived`。

`MID_ΔAcc = 2.0 pp`（解释阈值，唯一定义源为本节）。ΔAcc 三分类呈现：`> +MID` / `|ΔAcc| < MID`（写作"无重要差异"，禁写"等效"）/ `< −MID`。

### 1.3 四个子问题

| | 问题 | 主产出 | 可行性 |
|---|---|---|---|
| **RQ1** | 现有研究用了哪些基线、数据集切片、样本量与抽样方式？据此可划出哪些**可比评测组（EG）**？同 EG 同 backbone 的基线准确率**离散度 `δ_base`** 有多大？ | EG 划分表 + 基线分布 + `δ_base` | 必答 |
| **RQ2** | 同 EG、同模型规模带下，不同**代理数量档**的 ΔAcc / R / CEI 如何变化？是否存在**收益递减拐点**？ | 规模带 × 代理档矩阵（每 EG 三张：增益/成本/平衡） | 高 |
| **RQ3** | 固定代理档与规模带时，各**机制要素**各自带来多少增益、多少成本增量？哪些低成本高收益？ | 机制 ΔAcc–ΔR 散点 + Pareto 分区 | 中 |
| **RQ4** | 固定前三者时，不同**题目难度**下的 ΔAcc 与 CEI 如何变化？"对难题多花钱"是否有据？ | 难度 × 配置矩阵 | 条件（依赖难度分层数据） |

**综合产出（主结论）**：每个 EG 的 `Acc–R` **Pareto 前沿图**、**ICAR 排序表**、以及**推荐矩阵（题目难度 × 预算档 → 推荐配置）**。

**`δ_base` 的作用**：它是跨论文比较的解释门槛——**任何小于 `δ_base` 的跨论文差异都不构成证据**。这既是 RQ1 的产出，也是 RQ2–RQ4 中所有跨论文对比的判读标尺。

### 1.4 预设假设（各自独立检验，Holm 校正）

- **H1**：ΔAcc 随代理数/调用预算增加而递减（存在拐点）。
- **H2**：ΔAcc 与模型规模负相关（小模型从协作中获益更多）。
- **H3**：难题上的 ΔAcc 大于简单题；简单题上可能为负。
- **H4**：在同等调用预算下，MAS 相对 self-consistency@k 的增益不显著大于 0。

H4 是本综述最尖锐的一问：若成立，说明现有收益中相当部分来自"多花钱多采样"而非"协作"。

| 要素 | 本项目对应 | 声明 |

### 2.2 纳入标准（逐条可判定）

| 码 | 标准 |
|---|---|
| IN1 | 评价对象为 **LLM 驱动的多代理系统**（≥2 个代理，产生最终答案前有明确信息交换），或为其**内部消融**研究 |
| IN2 | 至少在一个**文本型医学考试式选择题**基准上报告准确率（主组/次级组见 §2.5） |
| IN3 | 报告可提取的数值结果（准确率或可换算量），且能识别所用题目集 |
| IN4 | 首次公开日期 **≥ 2022-01-01** |
| IN5 | 全文为**英文或中文** |
| IN6 | 报告原创实验的**同行评审**文献：期刊论文，或同行评审会议/workshop 论文（本领域会议即正式发表记录） |
| IN7 | 预印本仅在其证据不可由已发表文献替代时进入主分析，否则仅登记为背景；每条提取行必须携带 `pub_status` |

### 2.3 排除标准（仅保留无法由纳入标准否定表达的真正例外）

| 码 | 标准 | 理由 |
|---|---|---|
| EX1 | 主要输入为**图像/多模态**的任务 | 结局不可比；进证据地图但不进任何分析 |
| EX2 | 主要结局为**开放式生成**（无客观判分） | 结局不可比 |
| EX3 | 符合 IN1 但**既无匹配基线、也无任何内部消融**，且无法把 MAS 贡献与 RAG/工具/采样分离 | 无法计算任何差值，仅进证据地图 |

> 时间限制的科学理由（成稿句）：*Searches were restricted to 2022 onwards because LLM-based multi-agent collaboration was not technically feasible before the release of instruction-tuned conversational LLMs.*
> 语言限制的理由：英文为该领域主要发表语言；中文为评审团队工作语言，可直接从原文提取，避免机器翻译引入不可量化的提取误差。其他语言未纳入是因缺少对应语言的双语评审者，**检索端不设语言过滤器**，因语言排除的记录数与语言分布须报告。

### 2.4 report 与 study 的归并

同一工作的 arXiv 版 / 会议版 / 期刊扩展版是**一个 study 的多份 report**。判定信号：标题相似 + 作者重叠 + 系统名一致。以**最新正式版**为准，数据冲突时以正式版为准并记录冲突。流程图中同时给出"纳入 study 数"与"对应 report 数"。

### 2.5 评测组（EG）

**发表状态核实（v2.1 新增）**：每条记录的发表状态经 Semantic Scholar 批量接口与 OpenAlex 双源核实。arXiv 上若已被 NeurIPS/ICLR/ACL/EMNLP/AAAI/KDD 等同行评审会议接收，计为已发表。核实结果写入 `search/pubstatus.json`，并在 `documents.md` 按 Part 1（已发表+PDF）/ Part 2（已发表+仅全文）/ Part 3（已发表待手动）/ Part 4（预印本）/ Part 5（失败）分区登记。

**主组**（进主分析）：MedQA（注明语言版本与选项数）、MedMCQA、MMLU 医学子集（逐个列名：anatomy、clinical knowledge、college medicine、medical genetics、professional medicine、college biology 视实际情况定）。

**次级组**（单独报告，不与主组合并）：PubMedQA、MedBullets、MMLU-Pro health、中文医考（CMExam / CMB 等）。

EG 的划分键：`benchmark × split × 抽样方式`。抽样方式分三类：**全量 / 定种子子样 / 未说明抽样**。**不同抽样方式不得合并**。

## 3. 变量与分档（**暂定，G0 冻结**）

> 本节的分档与机制清单是**基于当前认识的初稿**。正式取值域在 §10.1 的 **G0 分类体系冻结**时确定——先做预检索与试编码，看清文献里实际存在什么，再冻结。冻结前不得开始正式提取。

### 3.1 多代理系统的判定

**纳入**：≥2 个由 LLM 驱动、具有不同角色/状态/推理轨迹的代理，在产生最终答案前通过明确的消息交换、审议、批评或层级聚合相互影响。

**单独编码为对照臂（不并入 MAS 主分析）**：无交互的多次采样（self-consistency）、简单多模型投票、单一 LLM 顺序扮演多角色而无独立状态、单代理 + RAG、单代理 + 工具。

### 3.2 模型规模带

按 `log₁₀(active parameters)`（MoE 用 active）。

- **严格同带**（主对比用）：差值 ≤ **0.15**（≈1.4× 以内）
- **宽松同带**（描述性表格用）：差值 ≤ **0.30**（≈2× 以内）

展示分档：S1 ≤4B｜S2 >4–10B｜S3 >10–35B｜S4 >35–90B｜S5 >90B 开源｜**S6 闭源未披露**（按厂商 × 版本 × 调用日期单独成层，**永不与 S1–S5 混合做规模推断**）。

> 0.15/0.30 为本综述预设约定（缩放律下等对数间距为自然尺度；主流开源家族发布间距约 2×，取其半可保证同带不跨发布档）。**是否有更权威的既有分档，检索阶段确认后可在 G0 替换。**

### 3.3 代理数量档与调用预算档（双轴）

| 代理数档 | 代理数 | | 预算档 | 每题调用数 |
|---|---|---|---|---|
| A1 | 2 | | B1 | ≤ 3 |
| A2 | 3–4 | | B2 | 4–9 |
| A3 | 5–7 | | B3 | 10–29 |
| A4 | ≥ 8 | | B4 | ≥ 30 |
| A5 | 动态/不定 | | | |

代理数是**结构**，调用预算是**代价**，二者必须同时呈现（5 代理 1 轮 ≠ 2 代理 5 轮）。

### 3.4 机制要素（正交 flags，**清单待 G0 冻结**）

当前候选，分四块：

- **交互结构**：`m_debate`、`m_topology`（full/star/chain/tree）、`m_hier`、`m_parallel`
- **信息流**：`m_context`（full/summary/answer_only）、`m_rag` + `m_rag_source`、`m_tool`、`m_memory`
- **角色与知识**：`m_role`、`m_role_type`（医学专科/通用功能）、`m_hetero`、`m_finetuned`
- **答案生成与质控**：`m_agg`（vote/judge/synthesis/rank）、`m_confidence`、`m_verify`、`m_selfrefine`、`m_abstain`
- **对照臂与控制策略**（非机制）：`ctl_selfconsistency`（Y/N + k）、`ctl_adaptive`

G0 时按"实际出现频次 ≥ 3 项研究"保留为独立 flag，低于该频次者并入 `other` 并在表注列名；同时从中指定 **≤6 个主对比因子**进入 Type B 主对比。

### 3.5 题目难度

证据分级：**L1** 数据集自带且经验证的标签 → **L2** 考生通过率/IRT/专家评级 → **L3** 由**独立于被评价系统**的单代理基线逐题正确率形成的预设分位组（允许本综述自建）→ **L4** 原作者未验证的标签（仅描述性）。

**禁止**：把 MMLU/MedMCQA/MedQA 直接当作低/中/高难度；用待评价系统自身的错误率定义难度。

难度与**题型/知识域**是两个维度，难度为主、题型为次级描述维度，且须声明两者可能混杂。

### 3.6 成本口径

优先序（取首个两臂都可得者，记入 `cost_metric_used`）：① 美元（**仅同论文同计价日**，禁止跨论文）→ ② 每题总 token → ③ 每题调用次数 × 平均上下文长度 → ④ 仅调用次数（标 `budget_granularity = coarse`）。跨层混算禁止。延迟单独记录，不并入 `R`。

## 4. 对照类型与公平性规则

### 4.1 匹配的三个层级

| 层级 | 条件 | 用途 |
|---|---|---|
| **核心三维匹配**（主分析准入） | 同 `model_checkpoint` + 同评测集（同 benchmark/split/子集）+ 同题目集（同题数或同 item 集） | 进主分析 |
| **严格匹配** | 核心三维 + prompt/解码对等 + 预算对等 | 进敏感性分析 S2 |
| **不匹配** | 核心三维任一不满足 | 仅进证据地图，不算 ΔAcc |

prompt/解码对等（`cot_parity`、`n_shots`、`temperature`、`n_runs`）与预算对等**记为变量，不作准入门槛**——这是相对 v1.1 的主要放宽。

### 4.2 三级对照

| 类型 | 定义 | 证据强度 | 允许的陈述 |
|---|---|---|---|
| **A** | 同一论文内 MAS vs 匹配单代理基线 | 高 | 可陈述 ΔAcc、R |
| **B** | 同一论文内**只变一个因子**的消融（代理数/机制/规模阶梯），其余固定 | 高 | **唯一可支撑调节性陈述的证据** |
| **C** | 不同论文但落在同一格（同 EG + 同规模带 + 同代理档 + 同机制） | 低 | **仅描述性**，必须与 `δ_base` 并列 |

**三条硬规则**
1. 任何"X 比 Y 好"的调节性陈述必须有 **Type B** 支撑；仅有 Type C 时写作"描述性差异 x pp，高于/低于同组基线离散度 `δ_base`"。
2. 对比某变量时其余变量必须落在同一格，做不到即降级为 Type C。
3. `m_rag = Y` 且基线无同等检索权限的行，**不进入任何"多代理协作收益"主表**，只进 RQ3 的 RAG 专项。

逐库记录：平台、覆盖年限、**精确检索日期**、命中数、检索式原文（存 `search/strategies/<db>_v<n>.txt`）。

### 5.3 限制

年份 ≥ 2022-01-01（理由见 §2.3）；**检索端不加语言过滤器**；不限文献类型（筛选阶段处理）。

### 5.4 sentinel 召回测试（硬门禁）

预检索阶段人工指定 **≥8 篇**确知应纳入的文献（记 `search/sentinel.md`，**待人工指定与核实，不得由 AI 代拟**）。检索式必须 **100% 命中**；未命中即回去改检索式（只能加同义词，不得删分面），每次迭代记录。通过后方可定版。

### 5.5 检索式同行评议

按 **PRESS** 六维（问题转换、布尔与邻近算符、受控词、自由词、拼写语法、限制与过滤器）请信息专家或同行复核一次，记录意见与修改。

## 6. 筛选与流程图

### 6.1 三阶段

| 阶段 | 依据 | 判定 |
|---|---|---|
| S1 标题 | 明显不相关即排除 | yes / maybe / no |
| S2 摘要 | 三问：是否 LLM 多代理？是否医学考试式 QA？是否原创实验？ | 任一明确为 no 即排除；任一不确定即 maybe |
| S3 全文 | 主要看**方法部分**：系统结构、基线、评测集、结果可提取性 | include / exclude + 唯一理由码 |

不确定一律留到下一阶段（"maybe 上浮"原则）。

### 6.2 人力与校准

双人独立为默认。**单人情形的合规替代**：全部记录单人筛选 + 对 ≥20% 随机样本间隔 ≥7 天重筛，并在条目 23c 如实声明。

校准轮：从去重后库随机抽 **≥50 条**（固定随机种子并记录）+ 强制追加 ≥10 条困难样本；两人独立判定，`Cohen's κ ≥ 0.70` 方可继续；未达标先澄清标准再重校，**最多 3 轮**。

### 6.3 排除理由编码（全文阶段，每篇只记一个主要理由）

| 码 | 理由 |
|---|---|
| X1 | 非 LLM 多代理系统（含单代理 + RAG / 工具） |
| X2 | 非医学考试式选择题任务 |
| X3 | 主要输入为多模态（EX1） |
| X4 | 主要结局为开放式生成（EX2） |
| X5 | 无可提取的数值结果 |
| X6 | 既无基线也无内部消融且贡献不可分离（EX3） |
| X7 | 非原创实验（综述/观点/演示） |
| X8 | 时间范围外 |
| X9 | 语言不符 |
| X10 | 全文不可获取 |

**X1–X6 中判为"看似合格却被排除"的研究须逐篇引用并说明理由**（PRISMA 条目 16b）。

### 6.4 流程图与计数

按 PRISMA 2020 模板（数据库/注册库 + 其他途径两栏）。计数表 `screening/flow_counts.csv` 字段：`stage, source, n_in, n_out, reason_code, date, screener`。自洽校验：每层 `in − out = 下一层 in`。

### 7.3 规则

- **预试**：先在 5 篇上双人试提取，修订后冻结为 `extraction/schema_v1.0.json`，此后变更走 §11.4。
- **双人独立提取** + 核对；差异率 >10% 触发重新校准。
- **基线臂选取**（多个合格基线时，按与结局无关的层级）：① `R` 最接近 1 者 → ② 论文自指的 main/default baseline → ③ prompt/shot 与 MAS 一致者 → ④ 配置最标准者（zero-shot direct ≻ CoT ≻ self-consistency）→ ⑤ `cond_id` 升序。**禁止按准确率选基线**（会改变 estimand 并引入 winner's curse）；"取准确率最高者"作为敏感性分析 S6 报告。
- **同一结局多个结果**：预设层级选出唯一 `primary = TRUE` 行；其余保留供敏感性分析。层级判据**不得引用任何结局数值**。
- **缺失**：一律记 `NR`，不推测。向作者索取数据的窗口 **21 天**，一次催询；未回复即记 `NR` 并报告。
- **成本缺失**：由架构推算 `R` 并标 `derived`；完全不可推算者只进准确率分析，不进 balance 分析。

## 8. 偏倚风险评价

RoB 2 / ROBINS-I 不适用（无随机化、无人类受试者）。采用**自建领域式框架**，随 protocol 预注册。**六个领域**，每个判 `low / some concerns / high` + 理由（须可追溯到原文位置）。

| 域 | 核心问题 | 判 high 的锚点（示例） |
|---|---|---|
| **D1 基线可比性** ★ | 基线是否同模型、同评测集、同题目集？ | 基线为不同 checkpoint；或基线数字来自他文引用 |
| **D2 评测集与抽样透明度** | 题目集、抽样方式、样本量是否可识别？ | 抽样方式与样本量均未报告 |
| **D3 模型版本可追溯性** | 是否报告精确 checkpoint 与调用日期？ | 仅写模型族名（如 "GPT-4"）且无日期 |
| **D4 随机性与不确定性** | 是否多次运行、是否报告波动？ | 单次运行且无任何区间/方差 |
| **D5 选择性报告** ★ | 是否只报最好的基准/运行/prompt？ | 方法称跑了 N 个基准，结果只报其中若干且无解释 |
| **D6 归因可分离性** ★ | 能否把 MAS 贡献与 RAG/工具/采样/额外预算分离？ | MAS 有 RAG 而基线没有，且无消融 |

★ = **关键领域**。总体判断规则：任一关键领域为 `high` → 总体 `high`；关键领域全 `low` 且非关键领域无 `high` → 总体 `low`；其余 → `some concerns`。

**禁止加总为分数**。评价流程：先在 3–5 篇上校准，双人独立，分歧讨论解决。

**如何进入综合**：D1 → 敏感性分析 S1；D5 → S3；D6 → S4（见 §9.4）。成本报告完整性单独记为描述性指标，**不计入偏倚判断**。

## 9. 分析计划

### 9.1 RQ1

- 建 EG 表（`benchmark × split × 抽样方式`），报告每组的 study 数、基线 Acc 中位数与全距。
- `δ_base` = 同 EG 同 backbone 的基线 Acc 极差；≥3 项研究方可计算，不足则记 `not estimable`。
- 抽样方式三类之间做描述性比较（不合并）。

### 9.2 RQ2

- 每个 EG 三张矩阵（行 = 代理档 A1–A5，列 = 规模带 S1–S6）：**表 A** `ΔAcc 中位数 [IQR] / k(m)`；**表 B** `R 中位数 [IQR]`；**表 C** `CEI 中位数`，并标出 Pareto 非受支配格（★）。
- 拐点：以调用预算为横轴拟合 ΔAcc 的分段线性或单调样条，报告拐点估计与不确定性；研究数 <8 时只做散点与描述，不拟合。
- H1/H2 用研究内配对差值的符号检验（Type B 行）。

### 9.3 RQ3 / RQ4

- RQ3：每个主对比因子给"有/无"两组的 ΔAcc 与 R 差，优先用 Type B；画机制 ΔAcc–ΔR 散点并分四象限（低成本高收益 / 高成本高收益 / 低成本低收益 / 受支配）。
- RQ4：难度档 × ΔAcc、难度档 × CEI；用研究内斜率符号检验（H3）；难度证据级别须同表标注；**不足 3 项研究提供分层结果时，RQ4 降级为"数据可得性调查"**，报告有多少研究提供逐题/分层结果、缺什么字段，并把"公开逐题预测"写成对未来研究的明确建议。

### 9.4 敏感性分析（6 项，全部执行并报告）

| # | 排除/改变什么 | 对应 |
|---|---|---|
| S1 | 排除 D1 = high 的行 | 基线可比性 |
| S2 | 仅保留**严格匹配**（含 prompt/预算对等）的行 | §4.1 |
| S3 | 排除 D5 = high 的行 | 选择性报告 |
| S4 | 排除使用 RAG/工具的行 | 归因约束 |
| S5 | 每个 study 只保留一个主要比较 | 非独立性 |
| S6 | 基线改取"准确率最高者" | 基线选取规则的稳健性 |

判定"结论是否改变"：① 汇总 ΔAcc 变化 ≥ `MID_ΔAcc` = 2.0 pp；② 方向反转；③ 纳入比较数减少 > 50%。任一命中记 `robust = FALSE`。

**亚组（4 个，预设）**：机制主因子、模型规模带、代理数档、难度档。k ≥ 5 才做交互作用检验，否则只描述。

### 9.5 综合方法

**默认路径 = SWiM 结构化综合**：按机制/代理档分组，标准化指标为 `ΔAcc`（pp）与 `R`（倍），呈现配对差值的中位数/IQR/全距 + 方向一致比例 + 符号检验，逐研究最低限度表必须包含：`study | 机制 | EG | ΔAcc | R | CEI | 匹配层级 | 偏倚总体 | 难度证据级`。

**定量合并为条件分支**：某格同时满足 ① `≥5` 个核心三维匹配比较行且来自 `≥3` 项独立 study；② 结局定义一致；③ 方差可得（逐题配对计数或 ≥3 次重复运行 SD）→ 做随机效应配对差值合并，标 `synthesis_tier = exploratory`；当 ① 提高到 `≥10` 行且 `≥5` study 时可标 `main`。**未达门槛即走 SWiM，不得用点估计近似方差顶替。**

**明确禁止**朴素 vote counting 作为主要综合方法；方向性计票只作描述性呈现并须与效应幅度、贡献研究数同表。

### 9.6 balance 专项

- **Pareto 前沿**：每个 EG 一张 `Acc`（横）–`R`（纵，对数轴）散点，标出非受支配配置。
- **ICAR 排序表**：按机制、代理档分别给 `(R−1)/ΔAcc` 的中位数与 IQR；`ΔAcc ≤ 0` 记 `dominated`。
- **推荐矩阵**：行 = 难度档，列 = 预算档 B1–B4，格 = 该条件下 Pareto 最优的配置及其证据强度。**这是全文的主结论产出。**
- 结论措辞与证据强度绑定：仅 Type C 支撑时一律写"描述性观察"，不得写"更优"。

### 9.7 报告偏倚与确信度

- 报告偏倚：某一综合内独立 study ≥10 且方差可得行占比 ≥70% 时做漏斗图 + Egger；否则明确写"研究数或方差不足，无法评估"，不用 fail-safe N 顶替。本领域特有形式：**只有跑赢基线的框架才会被发表**、**只报最好的运行/基准/prompt**。
- 确信度：**GRADE 改编**，四级（High/Moderate/Low/Very Low），逐维判断而非算术求和。默认起始 Moderate（配对设计强于观察性、但无盲法无预注册）。降级维度：偏倚风险、不一致性、**间接性**（考试选择题 → 临床推理能力，**本项目最重要的降级理由**）、不精确性、发表偏倚。每次降级写明理由。**准确率与成本分别评级。**
- 结论边界：明确区分 **efficacy**（基准条件下有效）与 **effectiveness**（真实临床中有效），不得跨越。

## 10. 两道门禁

### 10.1 G0 · 分类体系冻结（提取前）

**时点**：预检索完成、检索式定版后，正式提取之前。

**做什么**：从预检索结果中抽 **25 篇**代表性文献做试编码，**只编结构性字段**（代理数、轮数、机制要素、模型、基准、是否有基线、是否有消融、成本是否可推算），**不提取任何结局数值**（防止看到结果后再定分类）。

**冻结什么**：
1. 机制 flags 的最终清单（出现频次 ≥3 项研究者独立成 flag，低于者并入 `other` 并列名）
2. ≤6 个主对比因子的人选
3. 代理数档与预算档的切点（若实际分布与 §3.3 不符则据实调整）
4. 模型规模带切点的确认或替换
5. EG 的实际划分

**产出**：`protocol/codebook_v1.0.md` + `protocol/codebook_changelog.csv` + git tag `codebook-v1.0`。冻结后变更走 §11.4。

### 10.2 G1 · 可行性门禁（主分析前）

在同一批 25 篇上统计五个可得率：

| 指标 | 定义 | 决定什么 |
|---|---|---|
| P1 | 有核心三维匹配基线的研究占比 | 整个主分析能否成立 |
| P2 | `R` 可推算的研究占比 | balance 分析能否做 |
| P3 | 有代理数或机制**内部消融**的研究占比 | RQ2/RQ3 的 Type B 证据量 |
| P4 | 有难度分层或逐题结果的研究占比 | RQ4 能否做 |
| P5 | 有重复运行或区间的研究占比 | 能否定量合并 |

**决策规则**

| 条件 | 决定 |
|---|---|
| P1 ≥ 0.40 | 主分析照常 |
| 0.25 ≤ P1 < 0.40 | 主分析继续，但 `match_level` 成为强制分层维度，并在局限中说明 |
| P1 < 0.25 | **主产出改为证据地图 + 方法学缺口报告**，主问题改写为"当前证据能否回答平衡问题" |
| P2 < 0.50 | balance 分析降级为次级产出，正文以准确率为主、成本为辅 |
| P3 < 0.20 | RQ2/RQ3 的调节性结论降级为描述性（只保留 Type C） |
| P4 < 0.20 | **RQ4 转为数据可得性调查**（本身作为结论报告） |
| P5 < 0.30 | 放弃定量合并，全程 SWiM |

门禁结果写入 `gate/G1_summary.md` 并按 §11.4 登记；**不得跳过，不得在看到结局数值后回头修改判据**。
