# 08 · 证据综合与确信度（条目 13a–f、20a–d、14/21、15/22）

综合阶段是系统综述与"把文献读一遍写个总结"的分界线。PRISMA 2020 把综合方法拆成 6 个子条、综合结果拆成 4 个子条，就是为了堵住这里的含糊空间。

## 8.1 先决定：能不能做荟萃分析

荟萃分析的前提是**研究在临床与方法上足够相似，合并后的数字有意义**：

- 研究问题（PICO）足够同质
- 结局定义与测量方式可通约（或可标准化）
- 能提取效应量与其方差（或可从报告中推算）
- 研究之间相互独立（同一数据集的多次报告不能当独立研究）

任何一条不满足 → 不做荟萃分析，改走 SWiM（见 8.5）。**合并不了不是失败，硬合并才是。**

## 8.2 效应量与模型

### 常见效应量
| 结局类型 | 效应量 |
|---|---|
| 二分类 | 风险比 RR、比值比 OR、风险差 RD |
| 连续 | 均数差 MD、标准化均数差 SMD |
| 时间事件 | 风险比 HR |
| 相关 | Fisher z 转换后的 r |
| 配对/组内比较 | 差值及其配对标准误（**不能用独立样本公式**） |

Cohen's d 经验分级：0.2 小、0.5 中、0.8 大（Sawilowsky 扩展：0.01 极小、1.2 很大、2.0 巨大）。经验分级只是沟通用语，不能代替领域意义判断。

### 固定效应 vs 随机效应

| | 固定效应 | 随机效应 |
|---|---|---|
| 假设 | 所有研究估计同一个真实效应 | 各研究估计相关但不同的真实效应 |
| 变异来源 | 仅抽样误差 | 抽样误差 + 研究间真实差异 τ² |
| 推断对象 | 仅限纳入的这些研究 | 推广到所有可能的同类研究 |
| 权重 | 1/研究方差 | 1/(研究方差 + τ²) |

**选择依据是理论判断，不是异质性检验结果。** 先看异质性再决定用哪个模型，是事后数据驱动的选择。

## 8.3 异质性

三类来源：
- **临床异质性**：对象、干预、结局的差异
- **方法学异质性**：设计与实施的差异
- **统计异质性**：结果数值的差异（前两者的外在表现）

指标：
- **Cochran's Q**：检验异质性是否显著，阈值用 **p < 0.10**（因该检验功效低）
- **I²**：异质性占总变异的百分比。粗略参考：0–40% 可能不重要；30–60% 可能中等；50–90% 可能较大；75–100% 相当大
- **τ²**：研究间效应的方差，随机效应模型的核心参数
- **预测区间**：未来一项新研究的真实效应可能落在的范围——比 I² 更直观，强烈推荐同时报告

> **异质性是发现，不是需要消灭的问题。** 发现了大的异质性，任务是解释它（条目 13e/20c），不是换个模型把它藏起来。

探索方法：预设亚组分析（并报告**交互作用检验**，不是各亚组分别的显著性）、meta 回归（经验规则：每个协变量至少 10 项研究）。

## 8.4 敏感性分析（13f / 20d）

预先设定，常见维度：
- 排除高偏倚风险研究
- 排除样本量极小或极端值研究
- 换用另一种统计模型（固定↔随机）
- 换用另一种缺失数据处理方式
- 仅保留同行评议发表（排除预印本）
- 每项研究只保留一个主要比较（处理相关性）

**所有预设的敏感性分析都要报告结果**，包括"结论不变"。

## 8.5 不做荟萃分析时：SWiM 九条

出处：Campbell M, McKenzie JE, Sowden A, et al. *BMJ* 2020;368:l6890.

| # | 条目 |
|---|---|
| 1 | **研究分组**：如何把研究分组以进行综合，以及分组依据 |
| 2 | **标准化指标**：所用的标准化指标与转换方法 |
| 3 | **综合方法**：使用的综合方法及理由 |
| 4 | **结果优先级规则**：当一项研究有多个相容结果时，用什么标准挑选进入综合 |
| 5 | **异质性探索**：如何考察报告效应中的异质性 |
| 6 | **证据确信度**：如何评价证据体的确信度 |
| 7 | **数据呈现方法**：用什么表格/图形呈现 |
| 8 | **结果报告**：综合结果如何陈述 |
| 9 | **综合的局限**：该综合方法本身的局限 |

合规的替代综合方法（Popay 等的叙事综合四阶段）：
1. 建立干预如何起作用的理论
2. 形成初步综合（文字描述、聚类、指标标准化）
3. 探索数据中的关系（图形、概念图、三角验证）
4. 评估综合的稳健性

**最低限度**：一张表，含研究名、汇总统计量、置信区间、精确 p 值、意义判断列。

### 明确不合格的做法：vote counting

"3 项研究阳性、2 项无差异，所以有效"——不加权样本量、不产生任何汇总统计量。只有在回答"是否存在任何效应"这个极宽问题时才勉强可用，且必须说明其局限。**基于方向的计票**（按效应方向计数并做符号检验）比朴素计票稍好，但仍需明示。

## 8.6 报告偏倚（条目 14 / 21）

| 层面 | 含义 | 评估方式 |
|---|---|---|
| 研究间（发表偏倚） | 阳性结果更易发表 | 漏斗图（**≥10 项研究**才有意义）、Egger 回归检验、Begg 秩相关检验、trim-and-fill、fail-safe N |
| 研究内（选择性结局报告） | 测了但只报告好看的那个 | 比对 protocol/注册记录与发表结果（ORBIT 方法） |

漏斗图不对称不等于发表偏倚——也可能来自小样本研究质量差、真实的异质性。解释要谨慎。

计算类研究还有一种特有的报告偏倚：**只报告新方法表现最好的那次运行、那个数据集、那个 prompt**。应作为一个单独的偏倚领域来编码。

## 8.7 证据确信度：GRADE（条目 15 / 22）

四级：**High / Moderate / Low / Very Low**。

RCT 起始为 High，五个降级理由：
1. **偏倚风险**（risk of bias）
2. **不一致性**（inconsistency，即无法解释的异质性）
3. **间接性**（indirectness，人群/干预/结局与问题不符）
4. **不精确性**（imprecision，置信区间过宽）
5. **发表偏倚**（publication bias）

观察性研究起始为 Low，三个升级理由：
1. 效应量很大
2. 存在剂量反应关系
3. 残余混杂的方向与观察到的效应相反

**间接性**是技术类综述最常被低估的一条：在考试式选择题上的准确率提升，用来推断真实临床推理能力，属于典型的间接证据，应据此降级。

证据 → 推荐的四个判断维度：证据确信度、利弊平衡、价值与偏好、资源消耗。措辞约定：强推荐 "we recommend" / "clinicians should"；弱推荐 "we suggest" / "clinicians might"。

质性证据用 **GRADE-CERQual**（方法学局限、连贯性、数据充分性、相关性四个降级维度）；JBI 体系用 **ConQual**。

**Summary of Findings 表**（用 GRADEpro GDT 生成）：结局、研究数与人数、效应估计与区间、确信度等级、备注。

## 8.8 综合阶段自检

- [ ] 是否做荟萃分析的决定有明确依据，不是"能合就合"
- [ ] 模型选择（固定/随机）的理由是理论性的，不是看了 I² 之后定的
- [ ] 报告了 Q、I²、τ² 与预测区间
- [ ] 亚组分析是预设的，并报告了交互作用检验
- [ ] 所有预设敏感性分析都报告了结果
- [ ] 不做荟萃分析时，按 SWiM 九条逐条报告，没有停留在 "narrative synthesis"
- [ ] 没有使用朴素 vote counting 作为主要综合方法
- [ ] 研究数 ≥10 时做了漏斗图与非对称检验；<10 时明确说明无法评估
- [ ] 每个主要结局都有 GRADE 评级，且每次降级都写明理由
- [ ] 偏倚风险评价的结果真的进入了综合（至少通过一项敏感性分析）
