# 09 · 偏倚风险与批判性评价（条目 11 / 18）

## 9.1 四种"质量"必须分清

| 层面 | 名称 | 问的是 | 工具 |
|---|---|---|---|
| 单个研究 | 报告质量 | 论文写清楚了吗 | CONSORT、STROBE、COREQ（**报告规范**） |
| 单个研究 | 方法学质量 | 做得规范吗 | 设计专用工具 |
| 单个研究 | **偏倚风险** | 结果是否被系统性地扭曲 | RoB 2、ROBINS-I、QUADAS-2 |
| 证据体 | 证据确信度 | 这组证据整体多可信 | GRADE、CERQual |

**两条硬规则：**

1. **绝不能把报告规范当作偏倚风险评价工具。** CONSORT/PRISMA 是为"写"设计的，不是为"评"设计的。"这篇论文符合 CONSORT 20 条中的 15 条，所以质量中等"——方法学上不成立。
2. **偏倚 ≠ 不精确。** 偏倚是系统误差（例如检索式设计错误，会同等地影响所有结果）；不精确是随机误差（抽样波动，各研究表现不同）。两者的补救方式完全不同。

## 9.2 工具选择

| 研究类型 | 工具 |
|---|---|
| 随机对照试验 | **RoB 2**（5 个领域 + 信号问题 → Low / Some concerns / High） |
| 非随机干预研究 | **ROBINS-I**（7 个领域 → Low / Moderate / Serious / Critical） |
| 队列/病例对照 | Newcastle-Ottawa Scale（选择、可比性、暴露/结局） |
| 诊断准确性 | QUADAS-2 |
| 质性研究 | CASP（10 问，3 部分） |
| 预测模型 | PROBAST |
| 已发表的系统综述 | **AMSTAR 2**（16 条，7 条关键）/ **ROBIS** |

**原则：用针对特定设计的工具。** 声称能评价多种设计的通用工具通常很浅。

## 9.3 没有现成工具时怎么办（方法学/计算类综述的常态）

LLM/多代理系统的基准实验既不是 RCT 也不是观察性研究，RoB 2 与 ROBINS-I 都不直接适用。正确做法不是硬套，也不是跳过，而是：

1. **自建领域式评价框架，并在 protocol 中预注册。**
2. 每个领域给 **low / some concerns / high**（或 yes / partial / no）三级判断 **+ 判断理由**。
3. **不要加总成一个质量总分**——不同条目的含义与后果不同，单一分数无法传达意义。
4. 预先写明该评价**如何进入综合**（通常是敏感性分析）。

一个可用的领域清单示例（面向"模型—框架—基准"类研究）：

| 领域 | 核心问题 |
|---|---|
| 测试集选择 | 用了完整测试集还是抽样？抽样方法是否报告？ |
| 基线可比性 | 对照是否使用相同基础模型、相同外部信息权限、可比的推理预算？ |
| 模型可追溯性 | 是否报告精确模型版本与调用日期（闭源模型尤其关键）？ |
| 随机性处理 | 是否多次运行？是否报告方差/区间？temperature 与 seed 是否报告？ |
| 统计不确定性 | 是否给出置信区间或显著性检验，而非单点数字？ |
| 调参独立性 | 是否可能在测试集上调过 prompt/超参？ |
| 数据污染 | 是否检查训练数据污染（基准泄漏）？ |
| 选择性报告 | 是否只报告了表现最好的基准/运行/prompt？ |
| 可复现性 | 代码、prompt、逐题预测是否公开？ |
| 归因清晰度 | 能否把多代理的贡献与 RAG、工具、额外采样区分开？ |

可参考 **MI-CLAIM**、**METRICS**、**TRIPOD-LLM** 等清单获取条目灵感，但必须声明：它们是报告/评价框架，**不是经过验证的偏倚风险工具**（回到规则 1）。

## 9.4 评价的执行

- 双人独立评价，分歧讨论或第三人仲裁。
- 先在 3–5 篇上做校准（calibration），统一判断尺度后再铺开。
- 判断依据要记录到可核查的粒度（"第 4.2 节未报告随机种子"），而不是只留一个等级。
- 作者本人的研究若被纳入，应由未参与该研究的作者评价。

## 9.5 如何呈现（条目 18）

- 逐研究 × 逐领域的表格或 traffic-light 图（绿/黄/红）。
- 可附各领域判断分布的汇总条形图。
- **不要**只给一个总分或一个总体等级而不展示领域细节。

## 9.6 如何把评价用进综合（最常被跳过的一步）

三种合规用法：

1. **叙述性说明**：在结果与讨论中说明偏倚对解释的影响。
2. **敏感性分析**（推荐）：排除高偏倚风险研究后重跑综合，比较结论是否改变。
3. **限定纳入**：只综合低偏倚风险研究（会损失信息，需说明理由）。

> 文献中大量综述做完了精美的偏倚评价表，却在综合中完全不用它——这等于白做。protocol 的条目 14（PRISMA-P）就要求预先说明这一点。

## 9.7 评价证据体与评价综述本身

- 证据体的确信度 → GRADE（见 `08`）
- 你自己这篇综述的质量 → 在讨论的 23c 中自评，可用 **AMSTAR 2** 或 **ROBIS** 自查：
  - AMSTAR 2 的 7 个关键条目：protocol 是否预先注册、检索是否充分、排除理由是否说明、偏倚风险评价是否恰当、荟萃分析方法是否恰当、偏倚风险是否纳入结果解释、发表偏倚是否评估。
  - 任一关键条目不达标 → 整体可信度降为 Low 或 Critically Low。

## 9.8 自检

- [ ] 工具与研究设计匹配，没有用报告规范当评价工具
- [ ] 无现成工具时，自建领域已预注册且有明确判断规则
- [ ] 逐领域判断，没有合成总分
- [ ] 双人独立 + 校准 + 分歧解决机制已记录
- [ ] 判断理由可追溯到原文具体位置
- [ ] 偏倚评价结果通过敏感性分析进入了综合
- [ ] 已用 AMSTAR 2 对自己的综述自查一遍
